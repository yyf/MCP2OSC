# openFrameworks — MCP2OSC demo

## Setup

1. Install [openFrameworks](https://openframeworks.cc/) 0.12+
2. Create a new project with addon **ofxOsc**
3. Replace `src/` with the files in this folder’s `src/`
4. Build and run

## Addresses

| Address | Interaction |
|---------|-------------|
| `/mcp2osc/demo/slider` | Bar fill 0–1 |
| `/mcp2osc/demo/button` | Background toggle |
| `/mcp2osc/demo/preset` | Load preset 1–3 |

Listens on **UDP 9500**.
